Privacy policy

Your messages remain yours.

Threadmark is a personal, self-hosted attention assistant. It processes selected WhatsApp and Gmail sources to identify information that may require action.

Effective: 11 October 2026

Information Threadmark accesses

When a mailbox is connected, Threadmark uses the read-only Gmail scope to access the account address, mailbox history checkpoint, message identifiers, labels, sender and subject metadata, and the body of new messages from labels or senders the operator has enabled. It does not import messages that predate the connection checkpoint. Gmail attachments are not downloaded.

For selected WhatsApp sources, the linked-device connector receives new message text, limited source metadata and—only when attachment processing is enabled—temporary media needed for local extraction. Unselected message content is rejected before detection and long-term storage.

How the information is used

Threadmark uses selected content to detect payments, invoices, meetings, reminders, deliveries, family or school administration, software-development events and custom monitors. It creates a private attention item containing the relevant excerpt and workflow state. Gmail access is read-only: Threadmark cannot send, delete, modify or mark email as read.

Storage and retention

Application data is stored on the operator's self-hosted server. Gmail OAuth tokens are encrypted at rest, with separate credentials and synchronization checkpoints for the Personal and Dev profiles. Matched excerpts normally use a 30-day retention period; an open item can remain longer until resolved. Connector credentials, enabled-source metadata, settings and rules remain until deliberately removed.

Third-party processing

Gmail synchronization communicates with Google. WhatsApp linked-device operation communicates with WhatsApp infrastructure. If the operator enables Jev semantic detection, selected text may be transmitted to TypeSafe AI to return classification judgments. Threadmark intentionally omits source names, email addresses, phone numbers and provider message identifiers from those semantic requests. Provider-side handling is governed by the provider's own terms.

If browser notifications are enabled, an encrypted notification payload passes through the browser vendor's push service. Depending on device settings, notification text may appear on a lock screen.

Threadmark does not sell personal data, use Gmail data for advertising, or use Gmail data to train generalized artificial-intelligence models.

Google API Services disclosure
Threadmark's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

Threadmark uses encrypted Gmail token storage, private device invitations, HttpOnly session cookies, authenticated internal connector traffic and rootless containers. No system can eliminate all risk; anyone operating Threadmark should protect the server, backups and connected devices.

Your choices and deletion

  • Enable only the Gmail labels, senders and WhatsApp chats you want monitored.
  • Disable Jev to keep rule and detector processing on the self-hosted server.
  • Disconnect a mailbox in Threadmark or revoke access from your Google Account permissions.
  • Disable browser notifications or remove an authorized Threadmark device.
  • Delete the self-hosted data volumes to remove locally retained application data.
